How it works

The agents only propose. Plain code then checks every claim before anything is shown.

  1. 1

    Profiler

    Reads a transcript excerpt of each video and says what it teaches, quoting the transcript as proof.

  2. then, in parallel
  3. 2a

    Sequencer

    Puts the videos in a watch order, foundations first, and sets aside any video that does not serve the goal.

    2b

    Gap analyst

    Lists the areas the goal needs, marks each covered, partial or missing, and suggests what to search for.

  4. then
  5. 3

    Code verification (no AI)

    • Every quoted piece of evidence must exist in the transcript, otherwise the topic is removed.
    • Every video id must exist in the playlist, and each video appears in the order exactly once.
    • A "covered" claim must cite a real playlist video, otherwise it becomes "missing".
    • Suggested videos must be real YouTube search results, not invented titles.
  6. then
  7. 4

    Report

    The verified arrangement, topic coverage and suggested additions, shown below for each run.
